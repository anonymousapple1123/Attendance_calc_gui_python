## Graphical user interface of an attendance calculator
>How to install/run 
  ```
  All the instructions to install/compile or setting up the environment to run the application are provided in the file installationCommand.txt
  
  Pre-built binaries are available in release for windows.  (coming for linux and mac soon 🤞)
  ```
> How to use :
 ```
  1.First input field takes in the the number of lecture you were absent.
  2.Second input field takes in the input of total lectures to the date.
  3.For every selection button you will have a window pop up with the instructions.
```

### Scope of the program:
This program is currently limited to specific set of pre defined rules.
Rules that are pre-defined are :
  ```
  1.The fine is imposed of attendance lower than 90%.
  2.There in no maximum lectures known and no way to provide it to the program.
  3.There are eight lectures each day, and this value cannot be changed. ‼ UPDATE : The lectures per day can be changed now via json.
```
